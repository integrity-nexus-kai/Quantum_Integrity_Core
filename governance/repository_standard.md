# Repository Standard

## Purpose

This file defines the minimal repository governance standard for Quantum Integrity Core.

It is local governance scaffolding only.
It does not alter scientific status, paper status, or canonical claim boundaries.

---

## Required Root Boundary Files

The repository should maintain:

- `CANONICAL_STATUS.md`
- `AUTHOR.md`
- `REPOSITORY_MAP.md`
- `INTERFACE.md`
- `IMPORT_MANIFEST.md`
- `EXPORT_MANIFEST.md`
- `LM_EXPORT_MANIFEST.md`
- `OBJECT_OWNERSHIP.md`
- `LICENSE`
- `README.md`

---

## Recommended Governance Directories

The repository may maintain:

- `governance/`
- `registry/`
- `docs/`
- `papers/`
- `theory/`
- `topology/`
- `field_equations/`

---

## Status Boundary Rule

Status files must not silently override one another.

If repository status, paper status, and research status differ, the difference must remain visible.

---

## Audit Rule

Governance changes must preserve source paths, claim boundaries, and limitations.
