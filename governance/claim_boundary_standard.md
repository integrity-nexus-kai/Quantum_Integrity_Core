# Claim Boundary Standard

## Purpose

This file defines local claim-boundary rules for Quantum Integrity Core.

It is a governance file only.
It does not upgrade, validate, or derive claims.

---

## Boundary Classes

Allowed classes:

- structural note
- working assumption
- candidate construction
- reviewed construction
- paper draft material
- canonical repository material
- open problem
- limitation

---

## Required Boundary Rule

Every exported or summarized object should preserve its boundary class.

A lower-certainty class must not be presented as a higher-certainty class.

---

## Non-Escalation Rules

- Candidate material is not completed derivation.
- Working assumption is not proof.
- Paper draft is not final repository status.
- Compatibility statement is not derivation.
- Formal construction is not physical validation.

---

## Audit Rule

Any document that aggregates material from multiple paths should identify source paths and preserve unresolved dependencies.
