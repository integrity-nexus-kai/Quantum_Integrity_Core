## Purpose

This document defines the missing intermediate object between curvature and the Integrity Tensor.

The objective is not to construct the final Integrity Tensor.

The objective is to identify the first TIG-native geometric object that can measure loss of admissible organization.

# Core Idea

Curvature alone is not yet integrity.

Curvature becomes relevant to TIG only when it measures deviation from admissible organization.

Therefore, the next object is not immediately a tensor.

It is a defect measure.

---

# Definition

Let:

```text
R[g(ρ)]
```

denote the curvature generated by the organization-induced metric.

Let:

```text
R_adm[r_c]
```

denote the admissible curvature scale determined by the TIG integrity scale.

Define the Organizational Curvature Defect:

```text
D_OC[g,ρ,r_c]
=
R[g(ρ)]
-
R_adm[r_c]
```

---

# Interpretation

If:

```text
D_OC = 0
```

then curvature is compatible with admissible organization.

If:

```text
D_OC ≠ 0
```

then curvature deviates from admissible organization.

Thus:

```text
D_OC
```

is the first TIG-native object measuring structural deviation.

---

# Relation To Integrity

The Integrity Tensor should not be constructed directly from curvature alone.

It should be constructed from the defect between:

```text
generated curvature
```

and

```text
admissible curvature
```

Therefore the derivation chain becomes:

```text
ρ
↓
gμν(ρ)
↓
R[g(ρ)]
↓
D_OC[g,ρ,r_c]
↓
Integrity Tensor
```

---

# Minimal Requirement

The defect must vanish in the admissible sector:

```text
D_OC = 0
```

and remain finite in bounded-curvature regimes.
